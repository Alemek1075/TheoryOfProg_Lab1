# SIPL Debug

Розширення до курсового проєкту: підсвітка `.sipl` і дебагер через DAP.

Сам дебагер це Python-пакет `sipl-interpreter`, розширення тільки запускає `python -m sipl.dap`.
Тому спершу `pip install sipl-interpreter` (або `pip install -e .` з кореня репозиторію).
Якщо пакет стоїть не в тому python, що в PATH, його шлях задається в налаштуванні `sipl.python`.

Відкрити `.sipl`, поставити точку зупину і натиснути F5. Початковий стан задається в launch.json полем `state`.

Перевіряв на VS Code 1.80 і новіших.
